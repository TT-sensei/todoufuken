## 写真について
この段階では画面とデータ構造を確認するため、Wikimedia Commonsの画像を直接参照しています。これは最終仕様ではありません。次の作業で各画像を原ページ・作者・ライセンスと再照合し、長辺800px程度のWebPをリポジトリ内に配置して、オフラインでも表示できる形に切り替えます。

画像の加工・縮小を行った場合は、各カードに加工した旨を明記します。CC BY-SA画像の加工物は同一または互換ライセンスで扱う必要があります。パブリックドメイン画像は出典と作者情報を教材内に残します。
