# 都道府県マスター：県図鑑プロトタイプ（全国47都道府県）

本番版とは分離した試作ルートです。既存のクイズ、地図、MASTER条件、localStorageの保存キーには触れていません。

## 現在の試作内容
- 全国47都道府県を8地方に分けて表示・切り替え
- 5カテゴリ×47都道府県＝235項目のデータ構造
- 全235項目の具体的な説明文（食べ物47件、自然・名所・文化・工芸各40件を今回改稿）
- 各項目の短い説明
- 全235項目に公的機関・自治体などの調査用参考リンクを表示
- 写真カードと写真選定中カードの表示
- 写真ごとの作者・ライセンス・Commons原ページ表示
- タブレット／スマートフォン向けレイアウト
- 全国47都道府県の項目を名前・カテゴリ・説明文から横断検索
- 235項目すべてに、カテゴリに応じた調べる視点・問いを表示
- 検索範囲を全国47都道府県に拡張し、県別に検索結果をまとめて表示
- 写真の読み込みに失敗した場合の代替表示
- 関東7都県35項目のうち16点の写真候補について作者・ライセンスを確認（他地方200項目は写真未選定）
- 図鑑の閲覧はMASTER条件に影響しない

## 全国データの進捗
- 47都道府県、8地方、235項目を登録
- 全国235項目の説明文を具体化。食べ物47件、自然40件、名所40件、祭り40件、工芸40件を今回改稿
- 41項目は自治体・施設・観光協会などの個別資料、194項目は調査に使える公的な分野別資料へ接続
- 235項目すべてに参考資料リンクを登録。資料は調査の入口であり、各説明文の全記述を個別に照合済みという意味ではない
- 環境省・文化庁・農林水産省・経済産業省の公的資料を活用
- 地方区分は小学校社会科で扱いやすい8地方区分（北海道・東北・関東・中部・近畿・中国・四国・九州沖縄）

## 調べ学習の仕組み
- 各項目に「調べる視点」を追加。自然・名所・食・文化・工芸のカテゴリごとに問いを用意
- 「自分の住む地域や、ほかの都道府県と比べてみよう」と促し、情報を読むだけで終わらない設計
- 参考資料リンクには、そのページで確認できる内容を短く添えている

## 写真の進捗
- Commons原ページと作者・ライセンスを確認した写真：16点
- 写真の選定・権利確認が残っている項目：219点（全国235項目中、16点のみ写真情報を登録）
- ローカルWebP配置：未実施（次の作業）
- 写真の読み込み失敗時は代替表示するが、ネット接続なしでの閲覧には未対応
- 現在の写真表示はCommonsのSpecial:FilePathを参照する確認用です。最終仕様のB案ではありません。

写真の出典・作者・ライセンスは `data/prefecture-gallery.json` に項目単位で保持しています。原画像をローカル配置する際は、長辺800px程度へ変換し、`changes` に加工内容を記録します。CC BY-SA画像の改変物は同一または互換ライセンスで提供する必要があります。Commonsも、画像ごとにライセンスと作者を確認し、出典・ライセンス表示を行うよう案内しています。
